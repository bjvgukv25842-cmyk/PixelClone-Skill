# PixelClone v0.3：跨案例从零复刻验证计划

状态：已完成规划与输入边界确认，尚未执行正式运行。归档日期：2026-11-13。

## 目标与冻结规则

验证新版能否从零完成其他高难度案例，能否相较无 skill 和旧版提高复刻质量，以及独立重跑是否稳定。冻结 v0.3；首批 4 例完成后继续扩到 12 例，整个实验期间不根据反馈改 skill。Monopo 不参与新案例计分。

每次使用全新实现目录与上下文，仅提供该组 skill、任务说明和冻结输入；隔离其他组产物、历史 Monopo 实现、历史修复记录和参考站代码。正式实施前创建仅挂载允许输入的执行环境。

## 案例与输入

首批：Design2Code-Hard `g0.png`、DesignBench `generation/react/1/1.png`、Neutomni 的 preloader cut-along-line、Pixel Melbourne 的 menu directors hover。静态范围为整张截图；动态范围为对应交互及必要首屏/导航，不扩为整站。

后续：Design2Code-Hard `g20.png` / `g40.png` / `g60.png`，DesignBench vanilla / Vue / Angular 各 1 例，Palmo coconut crack scroll 和 Kavieng cards fly-to-grid drag。具体来源、版本与哈希沿用 `benchmarks/holdout.lock.json`。

已核对 8 个静态文件哈希。Neutomni、Pixel Melbourne 网页内容可访问，动画还未实测；Palmo、Kavieng 网页读取未成功，执行时需真实浏览器复核。四个动态任务及难度来源为 https://www.physera.ai/research/animation#appendix ，不把网页文字可访问当作采集成功。

- 截图模式只给锁定图像、尺寸和任务说明，不读参考 HTML、不推断动画。
- 网站模式允许截图、带时间戳录像、操作轨迹、原字体/图片/视频/纹理/模型、实际字体与浏览器计算样式及布局。
- 禁止读取应用 JavaScript、source map、原始样式实现、着色器源码和完整 HAR。浏览器可运行原站，但生成执行者不得提取实现。模型中的自定义着色器扩展也不进入输入包。
- 关闭 `renderAudit`；当前该功能会提取 shader source，不符合本次输入边界。
- 原视频可用；禁止把参考截图串成轮播替代实时交互，禁止将标题、按钮和菜单整体截图化。
- 冻结需求项、关键区域、锚点、素材来源、输入哈希。动态视口 1440×900 和触屏 390×844，DPR=1；静态用原图尺寸，不评判没有参考证据的移动端视觉。
- 参考重复采集三次。无法访问、效果消失、状态不同步时，先诊断并记录资格失败；只有正式运行前可记录理由并调整清单。正式运行后不因成绩差更换案例。

## 评测建设

保持冻结的 collect/fonts/capture/compare/report 接口，在独立编排层增加：实验清单（案例/组/重复编号/权限/版本/预算/环境/要求）、运行记录（首次/修正/用量/失败/证据/人工评价）、带实际时间戳的连续指针与滚动回放、按组与重复编号汇总。

现有 drag 主要是元素间拖放，另建连续 mouse-down/move/up 轨迹来测拖动和惯性；评测工具对三组提供相同检查条件。人工反馈增加保存到项目目录的本地入口，并保留导出备份。

## 验收

- 完成率：通过的预定需求项/全部需求项，未知不算通过。
- 视觉：pixelmatch 阈值 0.1，全页和每个关键区域差异均 ≤1%；锚点误差 ≤2 CSS px；关键换行一致。
- 动态：开始/25%/50%/75%/结束/停顿/反向或退出，并看完整录像。可测事件偏差 ≤max(100 ms, 参考阶段时长5%)；滚动触发点偏差 ≤该段范围2%；顺序、方向、返回行为一致，无漏段或截图回放替代。
- 先检查参考自身稳定性，不根据候选成绩放宽阈值；不能同步的动态指标仅诊断，不判严格通过。
- 功能：预定菜单、导航、键盘、触屏、减少动态效果、资源加载。
- 人工：视觉/完成/动效各评分，接受选项独立，未提供前为空；通过所有适用机器门槛并明确接受才判任务成功。
- 逐像素一致仅指对应截图原始 RGBA 相等。人工高分不覆盖机器失败；两次新版运行都通过才称该例重复成功。
- 正式失败/超时/未完成保留分母，待评审和基础设施错误单列；未收齐评价不宣布最终成功率。
- 截图不证明动态；视觉立体效果不证明真实几何、相机和光照。能力覆盖不足须明确说明。结果均为内部适配评测，不与官方榜单直接比较。

工具验证覆盖禁止输入混入、重复/重试计数、首次结果保留、错误帧时间戳、参考不稳定、字体/资源失败、移动溢出、人工为空不自动成功。
