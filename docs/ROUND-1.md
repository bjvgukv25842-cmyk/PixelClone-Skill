# 第二轮开发修复：字体质感与指针形变

2026-11-06。版本 v0.3.0 候选，尚未发布。

上一轮用户反馈：视觉 70、完成度 60、动效 40，不接受。原始反馈见 `feedback/monopo-r0.json`；截图保存在本地评审包中。本轮人工反馈已于 2026-11-13 归档，见文末。

## 根因和修复

- 旧实现加载了字体，但可见效果只是移动的圆形 DOM 覆盖层。原站实际使用 PixiJS 的文字栅格层、互补遮罩、位移纹理、RGB 色散和独立背景着色器。
- 新案例独立组装该渲染结构，使用原字体和纹理，保留可访问标题及原生控制。案例常量留在案例中，不加入通用 skill。
- 工具新增可选 `renderAudit`，记录有界的 Canvas 上下文、文字绘制、提交的着色器和来源哈希；新增控制台错误记录，避免漏掉不抛异常的 GPU 编译错误。采集支持真实触屏上下文，区别于缩小桌面视口。
- Skill 新增渲染证据合同：文字由谁绘制、图层/滤镜顺序、坐标与惯性、停顿/反向/退出状态、原资源缺口。字体加载、鼠标送达、字形变形、参考一致分别验收。
- 回归覆盖：字体区域关闭位移/色散确实改变像素，背景不变；真实指针、反向、减少动态效果、触屏、菜单、cookie、浏览器后退。修复两项独立审查发现：Canvas 文本被重复转换，及页面进入 BFCache 时误销毁渲染器。

## 评测边界

这一轮是基于反馈的**源码辅助开发修复**。网站模式增加了运行时和已公开源码证据，且由维护者直接修复案例；不是上一轮等预算三组试验，也不是新 skill 从零生成的成功率证明。独立技能应用检查验证了证据合同能被另一执行者使用，未证明完整复刻质量。

参考静态首屏重复采集三次；图像差异、关键区域及完整记录见本地 `round-1/reference/stability/stability.json`。逐状态截图包含标题、随指针移动的透镜、导航与底部文案；不会因全页差异低就略过失败区域。机器比例不是人眼相似度。

连续录像通过 CDP 记录浏览器帧时间，FFmpeg 使用原始帧间隔编码。原站时钟和帧调度未受控，录像用于诊断和人工观察，不声称严格同步动态通过。另保留真正触屏的移动端采集和减少动态效果检查。

本轮仍未宣布整页逐像素一致或完整动效验收通过。入场节奏、透镜跨到底部内容的边界、移动端菜单差异以及下游页面未复刻均保留在评审中。12 个独立验证案例没有运行、没有用于调优。下一次正式能力对照须冻结新的输入权限，在干净起点重跑。

本轮最终数值和版本哈希由 `outputs/pixelclone-review/round-1/evaluation.json` 与 `freeze.json` 记录。首轮输出和用户反馈均保留；新包不含原站商业字体和纹理。
